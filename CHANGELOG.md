# Changelog

## Unreleased

The C port of uxid: prefixed, K-sortable identifiers a person can read,
wire-compatible with the Elixir `uxid` package. No version has been released
yet. The build is in place: the CMake package `uxid` with the target
`uxid::uxid`, the pkg-config module `uxid`, a C11 floor and the build gate.
The generation, decoding and validity checks arrive in later changes.
